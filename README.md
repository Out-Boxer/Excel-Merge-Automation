# 주요 기능 및 목적
- 엑셀 표 병합(최대한 원본 서식 유지)
- 여러 개의 명단이나 표 리스트 등을 하나의 엑셀로 병합 시 일일이 복사 붙여넣기 하는 과정 귀찮음 해소
- 붙여넣기 시 무한 로딩 및 엑셀 멈춤 현상 및 멈춤 현상으로 인한 엑셀 비정상 종료 이슈 방지 목적
- 제작 당시에는 AI 에이전트나 AI 비서가 사용되기 전 시절이나 현재 AI 관련 보안 이슈가 지속적으로 제기되는 상황에 표 병합을 로컬에서 진행하여 혹시 모를 최대한 보안 사고를 최소화

# 제작 동기
- 공공기관에서 사무직 근무 당시 복사 붙여넣기 반복 작업 최소화 목적 (민원인의 방문 및 민원 전화가 잦은 부서라 시간 효율 중요!)
- PC 사양이 제각각이라 엑셀 대량 병합 시 저사양 PC에서의 문제는 물론이거니와 양이 많은 경우 적정 사양 PC에서도 문제 발생 >> 엑셀 복사 붙여넣기 로딩 문제는 유명
- 붙여넣기 시 무한 로딩 및 엑셀 멈춤 현상 및 엑셀 비정상 종료 이슈 해소(pc 사양에 따라 차이가 있지만 로딩 10분 이상 걸린 경우 O)
- 민원 전화가 왔는데 엑셀 로딩 이슈로 PC 사용 어려움을 겪는 경우 다수

- 파이썬 tkinter GUI
- 큐 자료구조

# 최근 변경사항

- 병합 작업이 실행 중일 때 창 닫기(X, Alt+F4)를 시도하면 안내창을 표시하고 종료를 막습니다.
- 병합 스레드의 실행 여부를 확인하므로 저장 및 정리 작업이 끝난 뒤 종료할 수 있습니다.
- 같은 원본 파일에서 상하좌우 테두리가 모두 있는 동일 서식을 캐시하여 재사용합니다. 일부 방향에만 있는 테두리는 기존처럼 복사합니다.
- 테두리 캐시는 원본 파일마다 별도로 생성하여 서로 다른 파일의 서식이 섞이지 않도록 합니다.

# 자동 테스트

프로젝트 루트에서 다음 명령을 실행합니다. Python과 프로젝트 실행에 필요한 openpyxl, tkinter가 설치되어 있어야 합니다.

```bash
python -m unittest discover -s tests -v
```

- 창 닫기 연결, 병합 중 종료 차단, 작업 완료·오류 후 종료, 저장 취소 및 입력 검증 실패 후 종료를 확인합니다.
- 동일 테두리 재사용, 부분 테두리 보존, 서로 다른 원본 파일을 실제로 병합·저장한 결과의 값과 테두리를 확인합니다.
- GUI 테스트는 창과 팝업을 모의 객체로 대체하므로 실제 창을 띄우지 않습니다.
